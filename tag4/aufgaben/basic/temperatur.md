# Eine Umrechnung als Funktion verwenden

**Schwerpunkt:** Berechnung und Darstellung trennen.

## Aufgabe

1. Schreibe `celsius_nach_fahrenheit(celsius)` nach der Formel Fahrenheit = Celsius × 9 / 5 + 32.
2. Liefere den Zahlenwert unverändert zurück. Erst das Hauptprogramm formatiert ihn mit einer Nachkommastelle.
3. Gib eine Tabelle für 0, 100 und -40 Grad Celsius aus.

## Prüfe dein Programm

- 0 °C ergibt 32 °F.
- 100 °C ergibt 212 °F.
- -40 °C ergibt -40 °F.
- Die Funktion gibt eine Zahl zurück und schreibt nichts auf die Konsole.

## Ausführen

Vom Hauptordner des Repositories:

```bash
python3 tag4/loesungen/basic/temperatur.py
```
