# Kursbelegungen vergleichen

**Schwerpunkt:** Vereinigung, Schnittmenge und Differenzen.

## Aufgabe

1. Verwende Python: Anna, Ben, Cem, Dora; SQL: Ben, Dora, Emil; Web: Anna, Emil, Frida.
2. Ermittle die Personen in mindestens einem Kurs und die gemeinsame Belegung von Python und SQL.
3. Ermittle die Personen, die nur Python und keinen der anderen Kurse besuchen.
4. Ermittle die Personen in genau einem der beiden Kurse Python und SQL. Die Web-Belegung spielt bei dieser letzten Frage keine Rolle.
5. Gib jede Ergebnismenge sortiert aus.

## Prüfe dein Programm

- Mindestens ein Kurs: Anna, Ben, Cem, Dora, Emil, Frida.
- Python und SQL: Ben, Dora.
- Nur Python: Cem.
- Genau Python oder SQL: Anna, Cem, Emil.
