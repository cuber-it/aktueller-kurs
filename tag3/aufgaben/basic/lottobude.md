# Sechs verschiedene Zahlen ziehen

**Schwerpunkt:** Eine Menge schrittweise aufbauen.

## Aufgabe

1. Erzeuge zufällige ganze Zahlen von 1 bis einschließlich 49.
2. Füge sie einem Set hinzu, bis es sechs Elemente enthält. Die Wiederholung wird über die Größe der Menge gesteuert.
3. Gib die sechs Werte aufsteigend sortiert aus.

## Prüfe dein Programm

- Jeder Lauf liefert genau sechs verschiedene Werte.
- Alle Zahlen liegen im Bereich 1 bis 49.
- Mehrfach gezogene Werte vergrößern die Menge nicht.
- Die Ausgabe ist sortiert; konkrete Zufallszahlen sind nicht vorgegeben.

## Erweiterung

- Erzeuge dieselbe Art von Tipp anschließend mit `random.sample()`.
